# Scripts

Place reusable analysis code here.

Suggested structure:

- `scripts/python/`: Python scripts for parsing, filtering, and summaries.
- `scripts/R/`: R scripts for statistics and visualization.
- `scripts/shell/`: Shell scripts or command wrappers for HPC runs.

Each script should include:

- A short header describing purpose.
- Expected input files.
- Main output files.
- Required software or packages.
