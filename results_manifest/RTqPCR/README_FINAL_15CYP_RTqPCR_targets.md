
## Sequence files

The final 15-CYP target sequences are stored in:

CDS nucleotide FASTA:
seqs/CYP_RTqPCR_true_targets.Figure1_15CYP.cds.gene_id_header.fa

Peptide FASTA with original TransDecoder peptide IDs:
seqs/CYP_RTqPCR_true_targets.Figure1_15CYP.pep.fa

Peptide FASTA with Trinity gene_id headers:
seqs/CYP_RTqPCR_true_targets.Figure1_15CYP.pep.gene_id_header.fa

For primer design, use the CDS nucleotide FASTA.

For protein-level annotation or peptide-length checks, use the peptide FASTA files.
