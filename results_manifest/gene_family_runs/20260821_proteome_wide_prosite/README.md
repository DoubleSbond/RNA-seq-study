# Whole-proteome PROSITE motif scan

All 11,856 longest *P. hoenei* peptides were scanned with EMBOSS `patmatmotifs` against the project-local PROSITE release downloaded on 2026-08-20. Both the pruned and full-pattern modes were retained.

- Pruned motif records: 5
- Full-pattern motif records: 35
- Tool stderr logs: empty
- Transferred files listed by the HPC manifest: all SHA-256 checks passed

This is an intentionally broad supplemental screen. PROSITE pattern matches alone do not establish family membership and should be interpreted together with Pfam, family HMM, homology, sequence architecture, and phylogeny.
