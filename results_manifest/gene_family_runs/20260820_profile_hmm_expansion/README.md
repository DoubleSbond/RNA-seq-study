Counts are deliberately permissive. Because profiles include all broad
candidates and shared protein folds, outside-pool hits can contain many false
positives. They are retained to minimize omission risk and are being annotated
against Swiss-Prot, Bombyx, and Spodoptera in a separate batch.

Raw profile HMMs, full HMMER output, tables, domain tables, Stockholm
alignments, all/current/novel gene lists, logs, summaries, inventories, and
checksums are included.
