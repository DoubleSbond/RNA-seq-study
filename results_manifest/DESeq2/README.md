# DESeq2 Results

This directory stores small, Git-friendly gene-level differential-expression result tables.

Current file:

- `DESeq2_results_significant.tsv`: significant gene-level DESeq2 results from the dandelion vs mulberry comparison.

The public reconstruction script is `scripts/R/gene_level_deseq2_final.R`. Raw Salmon `quant.sf` directories and full DESeq2 object files are kept outside Git.
