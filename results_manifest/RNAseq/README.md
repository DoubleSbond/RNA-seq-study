# RNA-seq Processing Manifests

This directory stores small public summaries for the upstream RNA-seq processing layer.

## Assembly QC

- `assembly_qc_summary.tsv`
- `trinity_length_histogram.tsv`

These files summarize the Trinity assembly and BUSCO completeness metrics. Large assembly FASTA files remain outside Git.

## Salmon Quantification

- `salmon_summary.tsv`

This table records Salmon version, processed reads, mapped reads, and mapping percentages for the six midgut RNA-seq samples.
