# P. hoenei–B. mori expression context v1

This package compares the shared functional-marker expression layers and CYP
context of the current *P. hoenei* dataset with six mulberry-fed *B. mori*
midgut libraries from PRJNA729897.

The tables intentionally retain an explicit comparability matrix. Differences
in tissue, diet design, genome/reference type, and transcript-versus-gene
aggregation prevent direct attribution of raw TPM ratios to species or feeding
habit. The appropriate current use is hypothesis generation, expression-rank
comparison, and selection of modules for a later matched analysis.

The accompanying workbook contains the shared-marker graph, complete B. mori
functional panel, family distributions, fixed-seed random background, CYP
summary, methods, and comparison limits.
