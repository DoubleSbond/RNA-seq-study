# B. mori mulberry-fed midgut expression background atlas v1

This package applies the same predefined functional-marker and fixed-seed
random-background design used for the *P. hoenei* atlas to six public *B. mori*
midgut RNA-seq libraries from PRJNA729897.

The six libraries comprise three female and three male mulberry-leaf midgut
samples. TPM values are transcript-level and use RefSeq annotation. The panel is
therefore suitable for within-dataset expression layers and cautious contextual
comparison, but not as a direct estimate of a species or feeding-habit effect.

Files follow the P. hoenei package names: functional representatives, matching
family distributions, fixed-seed random background, run metadata, and a
workbook containing source values and plots.
